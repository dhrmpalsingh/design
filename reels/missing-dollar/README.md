# The Missing Dollar (reel)

`missing-dollar.mp4`: 1:13, 720×1280. Three friends pay $10 each for a $30 hotel room. The room was only $25, so the bellhop takes $5 back, keeps $2 and returns $1 to each friend. "Each paid $9, 3 × $9 = $27, plus the bellhop's $2 = $29, so where's the missing dollar?" The answer: nothing is missing. The $27 already includes the $2 ($25 hotel + $2 bellhop), so the right sum is $27 + $3 returned = $30. A colour-coded $30 bar shows where each dollar went.

Built with `../kit`: narration in `lines.json`, scenes in `scenes.js`. Rebuild with `../kit/build.sh missing-dollar`.
