Also, 7 existing redirects point to it. Merging it now would delete a working page.

- **Product renames (fix 5, step 2).** Already done. No product name starts with "Pipihiri" any more.
- **Pottery Class page titles.** The page is still the theme's demo content: USD prices ($200–$300), mugs and bowls courses, and "0 satisfied students". New SEO text would describe classes the page doesn't show. The page content needs replacing first.
- **About URL rename.** The kit marks it optional and cosmetic.
- **Unboxing notice at checkout.** Payment runs in Razorpay's pop-up, and the cart and checkout pages are built from theme layouts, not page content. I added the notice to the checkout page content, saw it doesn't display, and reverted the change.
